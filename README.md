# アオリイカ釣果情報 / AORI INTEL

小浜・若狭湾周辺を中心に、公開Webのアオリイカ情報を **岸 / 船 / 定置網** に分離して収集・表示する軽量GitHub Pagesアプリです。

## 設計方針

- 地図を主画面にしない。地域別一覧を優先。
- 検索語は「アオリイカ」「アオリ」「エギング」「新子」「秋イカ」。誤表記「青り」は使わない。
- 岸と船を集計で混ぜない。
- 定置網は岸釣果の代用ではなく、アオリ・ベイト・捕食魚の回遊指標として別表示。
- `HIT` 数を杯数にしない。YAMARIA/エギCOMは1投稿=1捕獲イベントとして扱い、同一人物の近接投稿をセッション統合する。
- 「6杯目」等の本人表記は `claimed_count` として別保持し、写真確認数と区別する。
- 地名は辞書で正規化し、「小浜」と「小名浜」のような誤爆を除外する。
- 不明値は埋めない。

## 自動収集

`.github/workflows/collect.yml` が6時間ごとに固定情報源を巡回し、`data/` を更新します。

V1で自動処理する情報源:
- エギCOM 小浜
- エギCOM 敦賀
- 小浜市漁協 水揚げ情報
- 若狭小浜 おさかな探訪記（定置網帰属が明確な記事のみ）

`data/source-registry.json` には今後拡張するANGLERS、釣具店、遊漁船等も登録できます。

